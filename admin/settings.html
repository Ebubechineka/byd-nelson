Dealership contact details

These appear in the footer of every page and on the Contact page. Change them here, then press Save details and Publish.

Remember: saving here only changes this browser. Press Publish to live site on the admin dashboard to make the new details appear on the website.

GitHub access token

Paste a personal access token with repo scope. It is saved only in this browser (localStorage) — never in the site's files, and never sent anywhere except api.github.com.

Keep this private. Anyone with this token can change your repository. Don't share it, and revoke it at github.com/settings/tokens if you ever think it's been exposed.

How to create a token

Takes about a minute.

  1. Go to github.com/settings/tokens → Generate new token (classic)
  2. Give it a name like byd-nelson-admin
  3. Tick the repo checkbox
  4. Set an expiry (90 days is sensible)
  5. Click Generate token and copy the ghp_… value
  6. Paste it above and press Save token

Access & security

The admin panel now opens straight to the dashboard — there is no password screen any more. Publishing is protected by your GitHub token, which only you hold.

Anyone who finds this page can open the editor, but nothing can be published without your token. Keep the token private and never paste it into a chat or email.
